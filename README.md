# seminar_LP
セミナー申し込み用LPのリポジトリ


## フォーム送信処理（Google Apps Script）

このディレクトリの `code.js` は、LP の申込みフォームから送信された情報を受け取り、Google スプレッドシートへの保存と、参加者への自動返信メール送信を行う Google Apps Script です。

### 主な役割

- フォームの送信データを `doPost` で受け取る
- 必須項目をチェックする
- bot 対策用のハニーポット項目を確認する
- 参加希望枠に応じて対応する Zoom URL を取得する
- 申込み内容をスプレッドシートに1行ずつ保存する
- 参加者へ Zoom URL を含む確認メールを自動送信する
- 処理完了後、サンクスページへリダイレクトする

### 設定値

設定値は `CONFIG` にまとめています。主に以下を必要に応じて編集します。

- `SPREADSHEET_ID`  
  申込みデータの保存先となる Google スプレッドシート ID
- `SHEET_NAME`  
  保存先シート名
- `THANKS_URL`  
  送信完了後に遷移させる URL
- `ZOOM_URL_MAP`  
  開催日時ごとの Zoom URL の対応表
- `FROM_NAME`  
  自動返信メールの差出人名
- `MAIL_SUBJECT`  
  自動返信メールの件名

### 保存されるデータ

スプレッドシートには以下の項目を保存します。

- timestamp
- name
- email
- store_name
- slot
- prefecture
- city
- message
- page_url
- user_agent

初回書き込み時にシートが存在しない場合は自動で作成し、ヘッダー行も自動追加されます。

### 処理の流れ

1. LP の申込みフォームからデータを送信する  
2. `doPost` で送信データを受け取る  
3. ハニーポット項目と必須項目を確認する  
4. `slot` の値をもとに対応する Zoom URL を取得する  
5. 申込み内容をスプレッドシートへ保存する  
6. 参加者へ確認メールを送信する  
7. サンクスページへ遷移する  

### 注意点

- フロント側フォームの `slot` の選択肢と、GAS 側の `ZOOM_URL_MAP` のキーは必ず一致させてください
- 日程を変更する場合は、LP 側フォームと GAS 側設定を必ず同時に更新してください
- `SPREADSHEET_ID` や `THANKS_URL` を変更した場合は、公開前に動作確認を行ってください
- 自動返信メールは GmailApp を利用して送信されます

### 備考

LP 側ではフォーム送信時に `page_url` と `user_agent` も送信しているため、どのページからどの環境で申込みが行われたかを記録できます。  
また、送信完了後は GAS 側と LP 側の両方でサンクスページ遷移を補助する構成になっています。
